# Wedrink-Ramadan

WeDrink кафе желісіне (Түркістан) арналған **мобильді PWA** басқару панелі:
дашборд, қаржы есебі, кадр, активтер, қойма, каталог, CRM, OCR чек оқу, AI
көмекші және Supabase синхрондауы. Телефонға нағыз қосымша ретінде орнатылады
(офлайн жұмыс, өз иконкасы, толық экран) — App Store/Google Play қажет емес.

## Файлдар

- **`index.html`** — қосымшаның өзі (HTML + CSS + JS, build қажет емес).
- **`manifest.webmanifest`** — PWA манифесі (атау, икондар, түстер).
- **`sw.js`** — service worker (офлайн кэш / app shell).
- **`icons/`** — қосымша иконкалары (192/512/maskable/apple-touch).
- **`REVIEW.md`** — кәсіби код-ревью, түзетілген қателер және жақсарту жоспары.

## Іске қосу (хостинг)

PWA-ның офлайн пен орнату мүмкіндіктері үшін барлық файл **бір HTTPS мекенжайдан**
берілуі керек (`file://` ашуда қосымша істейді, бірақ орнатылмайды).

**GitHub Pages арқылы (ұсынылады):**
1. Репозиторий → **Settings → Pages**.
2. *Source*: `Deploy from a branch`, branch: `main` (немесе осы branch), folder: `/ (root)`.
3. Бірнеше минуттан соң берілген сілтемені телефонда ашыңыз.

## Телефонға орнату

- **Android (Chrome):** жоғарыдағы «Орнату» түймесін немесе браузер мәзірі →
  «Қосымшаны орнату / Негізгі экранға қосу».
- **iOS (Safari):** Бөлісу (Share) → «Негізгі экранға қосу».

## Деректер

Барлық дерек браузердің localStorage-ында сақталады. Бірнеше құрылғы
(телефон, ноутбук, кассалар) арасында синхрондау үшін Баптаулар → Синхрондау
бөлімінен Supabase қосыңыз. Сақтық көшірмені Баптаулар → Деректер бөлімінен
JSON етіп жүктеп алуға болады.
