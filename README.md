# Wedrink-Ramadan

WeDrink кафе желісіне (Түркістан) арналған бір файлды басқару панелі: дашборд,
қаржы есебі, кадр, активтер, қойма, каталог, CRM, OCR чек оқу, AI көмекші және
Supabase синхрондауы.

- **`index.html`** — қосымшаның өзі (HTML + CSS + JS, build қажет емес).
- **`REVIEW.md`** — кәсіби код-ревью, түзетілген қателер тізімі және жақсарту жоспары.

## Іске қосу

`index.html` файлын браузерден ашыңыз немесе статикалық хостингке (мыс. GitHub
Pages) жайғастырыңыз. Барлық дерек браузердің localStorage-ында сақталады;
бірнеше құрылғы арасында синхрондау үшін Баптаулар → Синхрондау бөлімінен
Supabase қосыңыз.
