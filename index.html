AI көмекші

Провайдер мен API кілті — деректеріңіз бойынша сұрақ-жауап
Anthropic API кілтін console.anthropic.com-нан аласыз. Claude.ai ішінде кілтсіз де істейді.
Тегін Gemini кілтін aistudio.google.com/apikey-ден аласыз (картасыз, тәулігіне ~1500 сұраныс). Қауіпсіздік үшін кілтті AI Studio-да сайтыңыздың сілтемесіне (HTTP referrer) шектеуге болады.
Ең қауіпсіз нұсқа: AI кілті Supabase серверінде сақталады, браузерде мүлде көрінбейді. Қосымша Supabase Edge Function-ға қосылады. Төмендегі функция кодын алып, Supabase жобаңызға орнатыңыз (нұсқаулықты бердім).
Кілт тек осы құрылғының браузерінде сақталады, бұлтқа жіберілмейді.

Құрылғыаралық синхрондау

Өшірулі
Supabase жобасын қоссаңыз, барлық дерек бұлтқа сақталып, бірнеше құрылғы (телефон, ноутбук, кассалар) арасында автоматты синхрондалады. Жоба деректемелерін Supabase → Project Settings → API бетінен алыңыз. Кесте жасау үшін төмендегі SQL-ді Supabase SQL Editor-да бір рет орындаңыз.
Кестені құру SQL-і (бір рет)
create table if not exists wedrink_state ( id text primary key, payload jsonb, rev bigint default 0, updated_at timestamptz default now() ); alter table wedrink_state enable row level security; create policy "wedrink all" on wedrink_state for all using (true) with check (true);

Деректер мен сақтық көшірме

Барлық деректер осы құрылғының браузерінде сақталады (localStorage). Файлды GitHub Pages-ке жайғастырғанда немесе тікелей ашқанда деректер сол браузерде қалады. Басқа құрылғыға көшіру үшін JSON сақтық көшірмесін жүктеп, екінші құрылғыда қалпына келтіріңіз. Кейін көп қолданушыға арнап Supabase-ке қосуға болады.
